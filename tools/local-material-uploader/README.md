# 电脑课程资料上传助手

用于在 Windows 电脑上直接选择 PPT/PPTX、PDF、Word/Excel、图片和音频，再由微信开发者工具上传到当前英语课程。

1. 双击 `start-local-material-uploader.cmd`，浏览器会自动打开。
2. 选择 1～20 个资料，点击“准备给小程序读取”。
3. 保持命令窗口开启，在微信开发者工具进入对应课程，展开“课件与资料”。
4. 先选择资料用途，再点击“读取电脑资料”。
5. 核对资料名称、数量、当前学生和课程，确认后才开始上传。

如果提示合法域名错误，请在微信开发者工具的“本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

助手只监听 `127.0.0.1:3211`。资料只存在进程内存中，关闭命令窗口即清除。助手不保存微信云密钥，实际上传由微信开发者工具中的教师账号完成。
