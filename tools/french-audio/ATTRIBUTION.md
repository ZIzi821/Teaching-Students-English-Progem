# French audio attribution

The French learning audio is generated with the Piper `fr_FR-siwis-medium` voice at 22,050 Hz.

- Voice model: `fr_FR-siwis-medium`, from [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/main/fr/fr_FR/siwis/medium)
- Verified model SHA-256: `641d1ab097da2b81128c076810edb052b385decc8be3381814802a64a73baf99`
- Source dataset: [SIWIS French Speech Synthesis Database](https://datashare.ed.ac.uk/handle/10283/2353)
- Dataset creators: Junichi Yamagishi, Pierre-Edouard Honnet, Philip Garner, and Alexandros Lazaridis; DOI [10.7488/ds/1705](https://doi.org/10.7488/ds/1705)
- Dataset license recorded by the model card: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Build engine: [OHF-Voice Piper](https://github.com/OHF-Voice/piper1-gpl), used only to generate the files and not included in the mini-program

Generated audio should retain this notice when redistributed. A human listener should approve pronunciation before the files are published to students.
