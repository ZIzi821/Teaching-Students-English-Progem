# 电脑本地错题导入助手

用于在 Windows 电脑上直接选择错题 JSON，不经过微信聊天。错题图片功能已经移除，助手不会读取或传输图片。

使用方法：

1. 准备包含完整题目、选项和答案的错题 JSON；每条必须有 `questionText`。
2. 双击 `start-local-importer.cmd`，浏览器会自动打开。
3. 在浏览器选择 JSON，点击“准备给小程序读取”。
4. 保持命令窗口开启，在微信开发者工具的对应课程中进入“批量导入错题”。
5. 点击“从电脑本地读取”，核对弹窗中的资料名称和当前课程。
6. 确认数量和课程正确后，再点击“确认批量导入”。

如果提示本地地址或合法域名错误，请在微信开发者工具的“本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。当前这台电脑已经设置为不校验。

助手只监听 `127.0.0.1:3210`。JSON 仅保存在进程内存中；关闭命令窗口后即清除。它不保存微信云密钥，实际导入仍由微信开发者工具中的老师账号完成。
